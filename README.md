## Хэсэг A: Category-Partition — `POST /transfer`

### Олон алдааны давуу эрэмбэ (тогтоосон)

**from → to → amount** (`ERROR_NO_FROM` → `ERROR_FROZEN` → `ERROR_NO_TO` → `ERROR_SAME_ACCOUNT` → `ERROR_BAD_AMOUNT` → `ERROR_INSUFFICIENT` → `ERROR_LIMIT`) — илгээгч данс байхгүй бол үлдэгдэл, лимит, хүлээн авагчтай харьцуулах суурь байхгүй тул эхлээд from-ийг, дараа нь to-г, хамгийн сүүлд хөрвүүлсний дараах дүнгийн (үлдэгдэл нь лимитээс өмнө) шалгалтыг хийнэ гэж үзсэн.

### A1 — Сонголт ба төлөөлөх утгууд

| Параметр / орчин | Сонголт (category) | Төлөөлөх утгууд |
|---|---|---|
| **from** | Данс байгаа эсэх, төлөв | F1 хүчинтэй (идэвхтэй) · F2 царцаагдсан · F3 байхгүй ID |
| **to** | Данс байгаа эсэх, from-тэй харьцаа | T1 хүчинтэй, from-оос өөр · T2 байхгүй ID · T3 from-тэй ижил |
| **amount** (хөрвүүлсний дараах дүн) | Тэмдэг, үлдэгдэл ба үлдсэн лимиттэй харьцаа | A1 ≤ 0 (0, −5) · A2 энгийн (0 < a < min(үлдэгдэл, үлдсэн лимит)) · A3 = үлдэгдэл яг · A4 > үлдэгдэл · A5 > үлдсэн лимит (≤ үлдэгдэл) · A6 = үлдсэн лимит яг |
| **currency** | Дансны валюттай харьцаа | C1 ижил (хөрвүүлэлтгүй) · C2 өөр (ханшаар хөрвүүлнэ) |
| **Далд орчин: өдрийн лимит хэр дүүрсэн** | Өнөөдөр өмнө нь хийсэн шилжүүлгийн нийлбэр | L1 огт ашиглаагүй · L2 хэсэгчлэн ашигласан |

Далд орчны сонголт бий: (1) өдрийн лимитийн өмнөх ашиглалт — ижил дүн L1-д амжилттай, L2-д `ERROR_LIMIT` болж болно; (2) ханш — C2 үед түүхий дүн үлдэгдлээс бага ч хөрвүүлсний дараа хэтэрч болно (A4-ийн дотор тусад нь тестлэв).

### A2 — Хязгаарлалтууд

| Утга | Тэмдэглэгээ | Үндэслэл |
|---|---|---|
| F2 царцаагдсан | **[ERROR]** | `ERROR_FROZEN` буцааж бусад параметрийг шалгахгүй тул нэг удаа шалгахад хангалттай. |
| F3 байхгүй | **[ERROR]** | `ERROR_NO_FROM` — үлдэгдэл/лимит тодорхойгүй тул бусадтай хослуулах утгагүй. |
| F1 хүчинтэй | **[property fromOK]** | to=T3 (ижил данс) ба amount-ийн үлдэгдэлтэй харьцаа зөвхөн from байгаа үед утгатай. |
| T2 байхгүй | **[ERROR]** | `ERROR_NO_TO` — нэг тохиолдол хангалттай. |
| T3 from-тэй ижил | **[ERROR] [IF fromOK]** | `ERROR_SAME_ACCOUNT` — from байхгүй бол "ижил" гэх ойлголт утгагүй. |
| A1 ≤ 0 | **[ERROR]** | `ERROR_BAD_AMOUNT` — валют, лимитээс үл хамааран алдаа. |
| A4 > үлдэгдэл | **[ERROR]** | `ERROR_INSUFFICIENT` — нэг удаа хангалттай (хөрвүүлэлттэй хувилбарыг тусад нь нэмэв). |
| A5 > үлдсэн лимит | **[ERROR]** | `ERROR_LIMIT`. |
| A3 = үлдэгдэл | **[SINGLE]** | Хязгаарын утга — нэг удаа шалгахад хангалттай, бусадтай хослуулбал тест үржинэ. |
| A6 = үлдсэн лимит | **[SINGLE]** | Лимитийн хил (≤ эсвэл <) — нэг удаа. |
| C2 өөр валют | **[property convert]** | Хөрвүүлэлттэй үед үлдэгдэл/лимитийн шалгалт хөрвүүлсэн дүнгээр явагдах ёстой. |
| L2 хэсэгчлэн | **[property limitUsed]** | A5/A6-г бодитоор хүргэхэд хэрэгтэй. |

**Тооцоо ("N → M"):**

- Бүрэн олонлог: 3 (from) × 3 (to) × 6 (amount) × 2 (currency) × 2 (лимит) = **216**
- Хязгаарлалтын дараа:
  - [ERROR] утга бүр нэг удаа: F2, F3, T2, T3, A1, A4, A5 = **7**
  - [SINGLE] утга бүр нэг удаа: A3, A6 = **2**
  - Үлдсэн хэвийн утгуудын үржвэр: F1 × T1 × A2 × (C1, C2) × (L1, L2) = 1·1·1·2·2 = **4**
- **216 → 13** спецификаци (+ давхар нөхцөл, хөрвүүлэлтийн тусгай тохиолдлыг гараар нэмэв)
